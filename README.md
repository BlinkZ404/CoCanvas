# CoCanvas

Planning a lightweight design canvas where a human and an AI agent can work on the same board.

## What it should feel like

- A simple canvas: frames, shapes, text, sticky notes, connectors.
- You draw and edit as usual.
- An agent can do the same kinds of actions on that live document, instead of only talking about the design in chat.

## Approach (TBD)

Looking at exposing canvas actions as in-page tools so an agent can read the current board and add or change things alongside you. WebMCP is a candidate for that.

This repo is in the planning stage. Implementation comes next.
